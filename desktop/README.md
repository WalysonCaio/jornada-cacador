# Instalador Windows

Este projeto cria um instalador de 64 bits para Windows 10/11. Ele abre a versão oficial da Jornada do Caçador dentro de uma janela própria, portanto usa a mesma conta, os mesmos PDFs e o mesmo progresso da versão web e do iPad.

Para gerar o `.exe`, execute `npm install` e `npm run build:windows` em um computador Windows, ou use a ação “Gerar instalador do Windows” no GitHub.
